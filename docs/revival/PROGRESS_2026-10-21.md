## What changed

### Crashes and lifecycle (Phase 0)
- **Threads.** Every detached thread is gone:
  - Separation runs on a joinable worker with cancel wired through to ONNX `SetTerminate`.
  - BPM, transient, quick-assign, spectral and WAV-export jobs run on a `SModeService` worker pool that is drained on shutdown.
  - The update check runs on a joinable thread and its HTTP request can be cancelled.
- **Async callbacks.** Every `callAsync` / `callAfterDelay` that touches `this` now checks a `SafePointer` or an alive token. This covers SModePage, StemWaveform, SequencerSlot, WaveDragArea, RootComponent, MidiMappingService, the processor and AppState.
- **Stale results.** Async results check `SModeSegmentModel::getContentGeneration()`, so an analysis finished for an old song is dropped instead of being applied to the new one.
- **Teardown.**
  - `~SModePage` stops the sequencer chain, unsubscribes `host.tempo` and detaches the model callbacks.
  - RootComponent unsubscribes every handler.
  - Eject now detaches the model callbacks (crash found by the layout work).
- **A6 multi-instance.**
  - ServiceLocator shutdown is owner-guarded and clears all four globals.
  - Live processors are tracked, and a surviving instance takes over the globals when another unloads.
  - The editor claims registry, bus, UI state and AppState for its own instance.
- **ServiceRegistry order.** Initialise runs in registration order; shutdown and destruction run in reverse. It used to follow `unordered_map` order.
- **Logging.**
  - All instances share one log file, and the global logger is cleared only by the last instance. The editor no longer replaces the global logger (A21).
  - The garbled progress log (UTF-8 passed to `%s`) is fixed.
- **Build.** `/arch:AVX` replaces AVX2, which crashed the whole DAW on pre-Haswell CPUs.

### Release hygiene
- **Customer machines.** No more `Desktop\oauth_debug.txt`. The `C:\Users\Public` DLL-load log is opt-in via `SAMPLAR_DLL_LOAD_TRACE=1`.
- **Installer contents.**
  - The installer excludes `*.map`, `*.pdb` and `logs/`.
  - Uninstall removes `portable_root.txt`.
  - `[InstallDelete]` cleans payload left by older versions.
- **Resource lookup.** The resources inside the bundle win over `portable_root.txt`.
- **One version number.** `project(samplar VERSION 1.0.1)` feeds `Version.h`, the JUCE metadata and `build_installer.ps1`. The stale "1.2.2" / "5.0.0" are gone.
- **Update check.**
  - Reads the server's `license_status` field.
  - Logs mask the hardware ID.
- **Payload removed.** ffmpeg (148 MB), pattern JSONs (56 MB), BACKGROUNDS (148 MB) and Samples (6 MB) had no runtime readers.
- **`.gitignore`.** `src/ui/Debug/` is no longer ignored, so a fresh clone builds. `openclaw/` is untracked.

### Licensing (SM5 port)
See `impl_licensing.md`.
- **Sign-in.** PKCE OAuth on 127.0.0.1 with a 5-minute timeout and Cancel. An in-window sign-in panel replaces the modal loop.
- **Verification.** Licences carry an RSA signature checked against an embedded public key. The forgeable HMAC is deleted.
- **Offline use.** Background revalidation, offline grace and a clock-rollback guard. A local check failure never wipes the cache.
- **Cleanup.** Logs are masked and UI strings say SAMPLAR.

### GPU separation (SM5 port)
See `impl_directml.md`.
- **Runtime.** ONNX Runtime 1.19.2 DirectML build + DirectML 1.15.1.
- **Model.** `htdemucs_body.onnx` with a C++ iSTFT (pffft) for both CPU and GPU, so a single model ships.
- **GPU handling.** Adapter probe, process-wide GPU-failed fallback, and a Settings toggle with a backend label.
- **Stem cache.** Persistent, 32-bit float stems; stems are matched exactly.
- **Long songs.** Bounded memory; songs over 20 minutes are refused with a message.
- **Installer.** 281.6 MB → 243.2 MB.
- **Song replaced mid-separation.** Dropping a new song cancels the current separation and starts the new one.

### Layout redesign
See `impl_layout.md`. PNGs are in the session scratchpad `sweep_final/`.
- **Top bar.** Responsive (Full / Medium / Compact plus a "..." menu). Window buttons sit in a zone the page reserves.
- **Empty state.** The overlay starts below the bar, and controls that need a song are disabled until one loads.
- **Stem lanes.** Stems keep at least 60% of the height. Three lane-header modes; the sequencer area scrolls and can be collapsed.
- **B32 performance.** Waveforms are cached as images: 28 ms → ~11 ms per frame for 4 lanes.

### Dead code deleted
68 source files, plus about 1,600 lines inside live files (MainWindow 1927 → ~1030 lines), plus 29k tracked junk files (libtorch, demucs.cpp, vcpkg, partial JUCE copy and others).
- **CMake dependencies dropped.** nlohmann_json, SoundTouch, ZeroMQ, Intel IPP, and the GPL Loop Tempo Estimator.
- **Removed with the dead coordinator service.** The GPL MiniBPM library, which was linked into the commercial plugin.
- **New tools.**
  - `tools/vst3_smoke_host`, ported from SM5 with `--ui-sweep` added.
  - `tools/separation_probe`.

## User actions required before shipping 1.0.1 (order matters)
1. **License server.** Upload `%USERPROFILE%\.samplar-keys\sampl4r_license_private.pem` (plus the public key) to `$KEYS_PATH/SAMPL4R/` on the Render disk. Then deploy the server patch (`license_server_sampl4r.patch`, same folder; local `license_server` is 36 commits behind origin) and check that the startup log shows the SAMPL4R pin. **Shipping the client before this locks every user out.**
2. **Security.** Rotate `LICENSE_TOKEN_SECRET` on Render and revoke the old PRO test licence (it is still in git history).
3. **Releases feed.** Set the `samplar` download URL and release date in the server's `releases.json`.
4. **Back up the key folder.** Keep `%USERPROFILE%\.samplar-keys\` somewhere safe (password manager or offline storage). Losing the private key means re-keying and shipping a new build.
5. **Test in real hosts.** Reaper / FL / Ableton, then a pristine VM install.

# Final pass (2026-10-21): unload profiling, licensing contract v2, cleanup
Reports: `impl_unload.md`, `impl_licensing3.md`, `impl_final_cleanup.md`.

- **Slow last-instance unload: root cause found.** JUCE releases the D3D11/Direct2D devices on the host's main thread; that kernel driver call blocks for longer the higher the CPU load (8-57 s under load). Fix: `src/plugin/GpuTeardownOffload.*` does the final release on a thread that pins the DLL and exits via `FreeLibraryAndExitThread`. The log file is now written by a background thread, and large buffers and idle thread pools are freed off-thread.

  | Load | Last-instance unload (median / p95 / max) | Over 1.5 s |
  |---|---|---|
  | Before the fix | 8.5 s median | 6/6 |
  | 6 busy processes | 15 / 24 / 617 ms | 0/32 |
  | 8 busy processes (100% CPU) | 16 / 37 / 898 ms | 0/32 |
- **Licensing client matches server contract v2.** The server side is license_server PR #132, owned by the license-server-42 session; it is not merged or deployed.
  - `token_*` replies trigger re-auth and keep the licence.
  - `503` replies honour Retry-After.
  - Signed denials are RSA-PSS (salt 32) and are acted on only when the nonce and hwid match the request.
  - The machine id is v2-only.
  - Offline window: signed `perpetual` = 30 days; dated expiries and PROMO/PROMO2/TRL = 3 days.
  - Removed: the OAUTH_SIGNING_KEY / app_signature (the server never verified it) and the test credentials in the docs.
- **New "Sign in again" banner + Settings state** (licence still valid, re-auth needed).
- **Editor reopen under saturated CPU:** median ~170 ms, max ~547 ms (was 2.3-3.4 s). About 85% of the remaining time is Windows/JUCE creating the window and its GPU surfaces.
- **Gate:** run_all_checks 7/7 PASS (918 unit checks); EngineTests and AnalysisTests green 3x each; session-roundtrip and bpm-unload pass.
- **N-17 resolved by the server owner:** 3 stale v1 SAMPL4R bindings in production get deactivated at deploy; no client fallback is needed.
